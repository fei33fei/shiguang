# 小米专属 0.3.5

仅修改小米分支，通用安卓、Windows、Mac、iOS 和鸿蒙运行代码保持原状。原版 0.3.3 与 0.3.4 安装包在本地保留。

## 本次功能

1. 设置 → 长期整理授权：先在系统允许全部照片，再开启媒体管理和原始位置信息授权。每次启动读取真实权限，不把保存过的标记当作授权。Android 的 createWriteRequest 修改授权绑定 Activity，系统明确不支持持久化；清后台后临时授权仍可能失效。只读选图授权（如聊天软件上传图片）与修改、移动原片不是同一种权限，不能据此承诺永久免确认。HyperOS 是否提供长期媒体管理仍需真机确认。
2. 首页“批量选择”：点选或全选当前筛选列表，然后“存入文件夹”。仍保留每个文件夹内逐张重新分类。逐项保存，失败时保留未处理选择；最近两次回退对应最近两张成功归档，不是整批撤销。
3. 相册显示名称支持 /、+ 等字符；/ 等非法目录字符转换为 ~sg~ 开头的安全磁盘名称，避免生成多级路径。重命名仍保留原存储目录标识。
4. 刷新时扫描当前有权访问的 Pictures/拾光、Movies/拾光 下的目录与媒体，恢复本地分类并按实际位置归类，保留已有自定义顺序和待删除标记。覆盖安装确实会保留应用数据；现在同时支持从本地目录发现分类。系统不允许读取的目录无法恢复，旧缓存分类不自动删除；系统拒绝创建空目录时先保存空分类，首张归档时再创建磁盘目录。
5. 照片及视频封面的整个展示区可滑动；内置视频页加入左滑下一张、右滑上一张，返回整理窗口显示相邻媒体，点开可播放。进度控制弹层仍由播放器处理。
6. 设置 → 检查 GitHub 小米版更新：仅主动点击时联网，不上传照片。只挑选 Xiaomi-Civi4.apk 命名的更高版本，下载后检查 GitHub SHA-256、包名、签名及版本码，再交给系统确认安装。首次需允许拾光安装应用，不能静默更新，也不能省去下载安装包。
7. 新版本发布在 https://github.com/fei33fei/shiguang/releases/tag/xiaomi-v0.3.5 。
8. 管理按钮同排、同高，从左到右为重命名、删除、上移、下移。

## 安装与验证

下载 Shiguang-Android-0.3.5-Xiaomi-Civi4.apk，直接覆盖安装，不要卸载或清数据。包名和签名沿用原版，versionCode 10。

已通过原生 API 35 编译、签名验证和浏览器交互测试：20 个分类排序及持久化、失败保存回退、目录发现、特殊字符、批量移动桥接、视频封面滑动、按钮布局和更新入口。桥接模拟不能代替真机，长期权限、原生视频手势和系统安装更新需在 Civi 4 Pro 上复测。原有系统回收站逻辑未替换为永久删除，小米相册“最近删除”展示差异仍保留原版边界。

构建：在仓库根目录运行 powershell -ExecutionPolicy Bypass -File variants/xiaomi/build.ps1。使用根目录 .tools 的 SDK 和 android/signing 的原签名（不提交私钥）。

官方权限说明：https://developer.android.com/reference/android/provider/MediaStore#createWriteRequest(android.content.ContentResolver,%20java.util.Collection%3Candroid.net.Uri%3E)
