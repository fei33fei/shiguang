# 通用安卓版 0.3.5

与小米专属 0.3.5 同步：主页批量归档、本地拾光目录发现、特殊字符显示名称、管理文件夹排序、视频展示区手势、长期授权引导与 GitHub 检查/下载更新。原来的单张二次整理和系统回收逻辑保留。

本分支使用标准 Android 媒体接口及通用系统相册入口，不依赖小米包名；媒体管理设置不存在时回到应用设置。设置中检查更新只选择 `Shiguang-Android-版本号-universal.apk`，不会自动安装小米专属包。

## 安装

[下载通用 APK](https://github.com/fei33fei/shiguang/releases/download/android-v0.3.5/Shiguang-Android-0.3.5-universal.apk)，直接覆盖旧通用版，不要卸载或清数据。包名与原签名保持一致；显示版本 0.3.5，内部版本码 11。Android 11+。两种安卓分支使用相同包名和签名，不能同时安装；手动切换分支受内部版本码限制，应用内更新不会跨分支。

首次需手动覆盖安装本版，后续可在“设置 → 检查 GitHub 通用安卓版更新”中下载，并由系统确认安装。安装前核对 SHA-256、包名、签名与版本码，不提供静默安装。

## 使用及边界

- “管理”里的重命名、删除、上移、下移在同一排，排序同步首页与整理页并持久保存。
- 首页“批量选择”后点选或全选当前列表，再“存入文件夹”；保留原有单张二次整理。逐项保存，失败保留未处理选择；两次回退对应最近两项成功归档，不是整批撤销。
- 名称支持 `/`、`+` 等，磁盘非法字符会转换为安全目录名称。刷新扫描有权访问的 `Pictures/拾光`、`Movies/拾光` 目录与媒体，恢复分类；读取受限的目录不能保证完整恢复，旧缓存分类不自动删除。空目录创建被系统拒绝时先保留分类，首张归档时再建目录。
- “长期整理授权”引导设置全部照片、媒体管理及原始位置信息权限。临时批量修改授权绑定 Activity，不能永久保存。各厂商系统不开放长期媒体管理时，清后台后仍可能重新批量确认。
- 整个照片/视频封面展示区可滑动；内置视频页左滑下一张、右滑上一张，返回整理窗口显示相邻媒体。播放器进度控制弹层仍由系统播放器处理。
- 首次删除为待删除标记，二次清理请求系统媒体回收，不调用永久删除。厂商相册的私有“最近删除”展示可能不同。
- 只有主动检查或下载更新时联网，不上传照片。各品牌的权限、原生手势、解码和系统安装仍待真机验证，不能把界面模拟当作实机适配完成。

## 构建

仓库根目录执行 `powershell -ExecutionPolicy Bypass -File variants/android-universal/build.ps1`。需要根目录 `.tools` SDK 与 `android/signing` 原签名。签名材料不上传仓库。

本分支独立于共用 `web`，不会把安卓新界面同步进尚未验收的 Windows、Mac、iOS、鸿蒙工程；小米专属分支也保持原样。
