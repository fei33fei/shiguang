相册权限

“允许全部相册”会打开系统应用设置，请进入权限 → 照片和视频 → 允许所有。只选部分照片也能整理：批量确认当前这一批，新照片加入后再补授权。批量整理权限可能在关闭应用后失效；媒体管理可配合对应类型的全部访问与原始照片权限减少重复授权。

本地文件夹

读取当前有权访问的媒体目录。App 自动建的文件夹不代表已经整理过。可按来源查看，或将该目录里现有的待整理照片标为已整理；以后新增的照片仍待整理。
